# Carbon-budget literature reviewed

Running list of ALL literature reviewed while building the CO2 + CH4 carbon budget
(NECB + lateral export + burial + biomass + allocation). Cite as appropriate in the
paper whether or not a budget value was taken. Status key:
- **USED** — a budget value is taken from it (term noted)
- **CONTEXT** — reviewed/compared but no value used (analog, superseded, corroborating, or method)
- **PENDING** — under review by an active agent (values not yet extracted)

Last updated: 2026-10-02. Sources: deep-research workflow + targeted agents (David Ho,
Castañeda biomass, Troxler Reco, CWD, 8-URL cross-check). Append as agents return.

## Provenance note (measured vs compiled)
Neither Ho 2017 nor Barr 2010 *measured* the full budget. **Measured primary values:** our chambers (Reco/CH4 components), our US-SKR tower (GPP/NEE 2022-23), CARAFE (top-down NEE/CH4), Ho/Reithmaier/Volta (dissolved DIC/DOC via SF6/surveys), Romigh (DOC flume), Castañeda (biometric wood/litter/root NPP), Breithaupt/Zhao (soil-core burial), Troxler (chamber Reco). **Compiled/synthesised (reuse the above):** Ho 2017 NECB (litter/wood/root from Castañeda, burial from Breithaupt, NEE from Barr) and Barr 2010 Table 4 (lateral export from Romigh/Twilley/Heald/Bouillon, burial from Duarte). So the ~950–1000 NECB agreement across Ho/Barr/us is partly circular — the genuinely independent cross-checks are tower-vs-CARAFE (NEE) and chamber-vs-Troxler (Reco).
