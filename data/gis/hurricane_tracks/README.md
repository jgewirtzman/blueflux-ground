# Atlantic hurricane best tracks (HURDAT2)

NOAA National Hurricane Center Atlantic hurricane database (HURDAT2),
`hurdat2-1851-2025-092326.txt`, from https://www.nhc.noaa.gov/data/hurdat/
(Landsea & Franklin 2013, Mon. Wea. Rev. 141:3576). Not committed (7 MB);
`code/07_upscaling/09_regional_scaling.R` downloads it if missing and reads the
2017 tracks of Hurricanes Irma (AL112017) and Maria (AL152017) for the regional
map.
