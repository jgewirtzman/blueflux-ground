# South Florida mangrove extent, 2016 (display layer for Fig. 1)

`gmw_v3_2016_sfl.gpkg`: Global Mangrove Watch v3.0 2016 extent (Bunting P et al. 2022, Remote Sensing 14:3657;
Zenodo doi:10.5281/zenodo.6894273; CC BY 4.0), tiles N25-N27 / W081-W082, cropped to 24.7-26.4 N, 82-80 W,
aggregated to ~100 m and polygonised. Built by `code/07_upscaling/01d_mangrove_extent.R` (downloads the
66 MB archive only if this file is missing). Display only; not used in any calculation.
