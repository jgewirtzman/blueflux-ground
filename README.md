# BlueFlux Ground

Greenhouse gas (CO2 and CH4) flux measurements from mangrove and coastal wetland ecosystems across south Florida, collected as part of the NASA Carbon Monitoring System BlueFlux field campaign (March 2022 - March 2023).

## Directory Structure

```
blueflux-ground/
├── data/                      # Input data (read-only)
│   ├── analyzer/              # Raw instrument data (gitignored, ~1 GB)
│   │   ├── LGR_GLA131/       # Los Gatos Research analyzers (LGR1, LGR2, LGR3)
│   │   └── Picarro_G4301/    # Picarro analyzer
│   ├── field_notes/           # Field measurements and metadata
│   │   ├── entered_data/      # Manual data entry sheets
│   │   ├── dimension_calcs/   # Chamber volume calculations
│   │   └── dimension_csvs/    # Derived dimension CSVs
│   └── environmental/         # Environmental covariates
│       ├── salinity/          # Compiled salinity data (both seasons + transects)
│       └── porewater_gas/     # GC headspace CH4/CO2 concentrations
│
├── code/                      # Analysis scripts (numbered by workflow step)
│   ├── 01_import/             # Raw data import and extraction
│   ├── 02_preprocess/         # Chamber dimensions, auxfile creation, temp gap-filling
│   ├── 03_flux_calculation/   # goFlux processing (interactive, per analyzer x type)
│   ├── 04_qc_rescue/          # Quality control, manual ID, rescue workflows
│   ├── 05_integration/        # Dataset assembly, chamber volume corrections
│   ├── 06_ebullition/         # Ebullition detection, partitioning, reprocessing
│   ├── 07_analysis/           # Statistics, manuscript results, figures (one per display item)
│   └── helpers/               # Shared utility scripts
│
├── intermediate/              # Processing intermediates (gitignored, regenerated by code/)
│   ├── auxfiles/              # goFlux-format input files
│   ├── rescue/                # Rescued flux measurements
│   ├── results_trees/         # Per-analyzer tree flux results
│   ├── results_surface/       # Per-analyzer soil/water flux results
│   └── plots/                 # Diagnostic flux plots (PDFs)
│
├── output/                    # Final data products and manuscript outputs
│   ├── combined_gas_flux_dataset.csv   # 867 flux measurements, all components
│   ├── tree_stem_fluxes.csv
│   ├── soil_water_surface_fluxes.csv
│   ├── flux_statistics_table.csv       # Bootstrap means, CIs, per component x site x season
│   ├── manuscript_results.txt          # Computed results numbers
│   ├── manuscript_results_text.md      # Draft results and figure captions
│   ├── manuscript_methods_text.md      # Draft methods
│   ├── manuscript_intro_text.md        # Draft introduction
│   ├── data_dictionary.csv
│   ├── site_metadata.csv
│   ├── ebullition/            # Ebullition detection and partitioning outputs
│   └── figures/               # Main text and SI figures
│       └── archive/           # Exploratory and legacy figures
│
├── run_all.R                  # Master pipeline script (see Workflow below)
└── _archive/                  # Deprecated scripts (gitignored)
```

## Workflow

The full pipeline is orchestrated by `run_all.R`:

```bash
Rscript run_all.R       # run all steps
Rscript run_all.R 5     # run from step 5 onward
```

| Step | Script | Description |
|------|--------|-------------|
| 1 | `02_preprocess/assign_tree_vol_area.R` | Assign chamber volumes and surface areas |
| 2 | `02_preprocess/convert_to_auxfile.R` | Convert to goFlux auxfile format |
| 3 | `03_flux_calculation/*.R` | **Manual (RStudio):** goFlux processing with click.peak2 |
| 4 | `04_qc_rescue/build_missing_auxfiles.R` | Build auxfiles for rescued measurements |
| 5 | `05_integration/assemble_clean_dataset.R` | Assemble clean combined dataset |
| 6 | `05_integration/apply_chamber_corrections.R` | Apply HA/HB chamber volume corrections |
| 7 | `06_ebullition/detect_ebullition.R` | Detect ebullition in raw analyzer traces |
| 8 | `06_ebullition/goflux_reprocess_ebullition.R` | Reprocess water traces (diffusive/ebullitive partitioning) |
| 9 | `06_ebullition/integrate_ebullition.R` | Integrate ebullition water traces into dataset |
| 10 | `06_ebullition/apply_negative_flux_corrections.R` | Remove artifacts, apply corrected time windows |
| 11 | `07_analysis/summary_table.R` | Bootstrap statistics per component x site x season |
| 12 | `07_analysis/manuscript_results.R` | Compute all manuscript numbers |
| 13 | `07_analysis/publication_map_composite.R` | **Manual:** Fig 1 (map + photos) |
| 14 | `07_analysis/fig2_component_boot.R` | Fig 2: Component flux rates (bootstrapped) |
| 15 | `07_analysis/fig3_stem_height.R` | Fig 3: Stem height x species composite |
| 16 | `07_analysis/fig6_porewater_pca.R` | Fig 6: Porewater PCA + depth profiles |
| 17 | `07_analysis/figS1_ebullition.R` | Fig S1: Ebullition partitioning |
| 18 | `07_analysis/figS2_pneumatophore.R` | Fig S2: Pneumatophore density vs flux |
| 19 | `07_analysis/figure_cleanup.R` | Archive non-main figures |

Steps 3 and 13 require interactive RStudio sessions and are skipped by `run_all.R`.

## Instruments

- 3x Los Gatos Research UGGA (model GLA131) -- CO2 and CH4 at 1 Hz
- 1x Picarro G4301 -- CO2 and CH4 at 0.17 Hz

## Dependencies

```r

# Flux calculation
devtools::install_github("Qepanna/goFlux")

# Interactive QC app
install.packages(c("shiny", "plotly"))

# Figures and analysis
install.packages(c("patchwork", "ggh4x", "ggridges", "ggdist", "ggbeeswarm",
                    "ggrepel", "ggpubr", "cowplot", "scales", "forcats",
                    "lme4", "lmerTest", "emmeans"))

# Mapping
install.packages(c("sf", "rnaturalearth"))
```

Requires R >= 4.3.
