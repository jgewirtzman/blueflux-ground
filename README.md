# BlueFlux Ground

Greenhouse gas (CO2 and CH4) flux measurements from mangrove and coastal wetland ecosystems across south Florida, collected as part of the NASA Carbon Monitoring System BlueFlux field campaign (March 2022 - March 2023).

```

│   ├── analyzer/              # Raw instrument data (gitignored, ~1 GB)

│   │   ├── entered_data/      # Manual data entry sheets
│   │   ├── dimension_calcs/   # Chamber volume calculations
│   │   └── dimension_csvs/    # Derived dimension CSVs
│   └── environmental/         # Environmental covariates

│   ├── 02_preprocess/         # Metadata prep, auxfile creation, temp gap-filling
│   ├── 03_flux_calculation/   # goFlux processing (LGR + Picarro, trees + soil/water)
│   ├── 04_qc_rescue/          # Quality control, manual ID, rescue workflows
```

## Data Availability

**Raw analyzer data** (`data/analyzer/`) is not included in this repository due to size (~1 GB). Contact the PI or check ORNL DAAC for access.

**Final data products** are in `output/` and include the combined flux dataset, per-type subsets, a data dictionary, and site metadata.

## Workflow

Run scripts from the project root directory in RStudio. Each step reads from earlier outputs:

| Step | Directory | What it does |
|------|-----------|-------------|
| 1 | `code/01_import/` | Extract and import raw LGR analyzer data |
| 2 | `code/02_preprocess/` | Assign chamber dimensions, create goFlux auxfiles, gap-fill temperatures |
| 3 | `code/03_flux_calculation/` | Calculate CO2/CH4 fluxes using goFlux (per analyzer, per measurement type) |
| 4 | `code/04_qc_rescue/` | Manual quality control, rescue failed measurements |
| 5 | `code/05_integration/` | Combine all analyzer results, harmonize dates, merge rescued data |
| 6 | `code/06_ebullition/` | Detect ebullition in water flux traces, partition diffusive vs ebullitive CH4, reprocess through goFlux, correct negative flux artifacts |
| 7 | `code/07_analysis/` | Summary statistics, publication figures, data product creation |

See the README in each `code/` subdirectory for detailed run order.

## Instruments

- 3x Los Gatos Research UGGA (model GLA131) — CO2 and CH4
- 1x Picarro G4301 — CO2 and CH4
