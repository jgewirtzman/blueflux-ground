# BlueFlux Ground

Greenhouse gas (CO2 and CH4) flux measurements from mangrove and coastal wetland ecosystems across south Florida, collected as part of the NASA Carbon Monitoring System BlueFlux field campaign (March 2022 - March 2023).

## Directory Structure

```
blueflux-ground/
├── data/                      # Input data (read-only)
│   ├── analyzer/              # Raw instrument data (gitignored, ~1 GB)
│   ├── tower/                 # AmeriFlux US-Skr tower data (large CSV gitignored)
│   ├── field_notes/           # Chamber dimensions, entered data sheets
│   ├── environmental/         # Salinity, porewater gas covariates
│   ├── gis/  ├── spatial/     # Site coordinates and spatial layers
│
├── code/                      # Analysis scripts (numbered by workflow stage)
│   ├── 01_import/             # Raw analyzer import
│   ├── 02_preprocess/         # Chamber dimensions, auxfiles, temp gap-filling
│   ├── 03_flux_calculation/   # goFlux processing (interactive, per analyzer x type)
│   ├── 04_qc_rescue/          # QC, manual ID, rescue workflows
│   ├── 05_integration/        # Dataset assembly, chamber corrections
│   ├── 06_ebullition/         # Ebullition detection, partitioning, reprocessing
│   ├── 07_analysis/           # Summary stats, manuscript numbers, data products
│   ├── 08_upscaling/          # Chambers x TLS -> stand budgets; Monte Carlo forcing
│   ├── 09_tower_gpp/          # US-Skr tower GPP partitioning (input to 08 CO2)
│   ├── 10_figures/            # ALL figure-generating scripts
│   └── helpers/               # Shared utilities
│
├── intermediate/              # Processing intermediates (gitignored, regenerated by code/)
│
├── output/
│   ├── data_products/         # Shareable datasets (combined_gas_flux_dataset.csv, etc.)
│   ├── figures/
│   │   ├── main/              # Curated main-text figures (Fig 1-6)
│   │   ├── SI/                # Curated supplementary figures
│   │   ├── presentation/      # Conference-deck figures
│   │   └── other/             # Auto-generated candidates + archive (gitignored)
│   ├── upscaling/             # Plot-level budgets, net forcing, Monte Carlo
│   ├── carafe_topdown/        # Airborne two-end-member fluxes (closure)
│   ├── ebullition/            # Ebullition detection / partitioning outputs
│   └── gpp/                   # Tower GPP time series + diagnostics
│
├── manuscript/                # All manuscript text (not read by code)
│   ├── drafts/                # NCC draft + outline
│   ├── SI/                    # Supplementary Information + skeleton
│   ├── text/                  # Section drafts, computed results digest
│   └── literature/            # CO2-budget literature synthesis & value catalog
│
├── run_all.R                  # Master pipeline (see Workflow)
└── _archive/                  # Deprecated / superseded files (gitignored)
```

Scripts self-anchor to the project root with `here::here()`, so they run from any working directory. TLS surface-area products and porewater/geochemistry data are bundled in `data/tls/` and `data/porewater/`; the scripts default to those in-repo copies but accept `BLUEFLUX_TLS_DIR` / `BLUEFLUX_MICROBES_DIR` env vars to point elsewhere. Raw analyzer traces (`data/analyzer/`, ~278 MB) and the raw AmeriFlux tower record (`data/tower/`, ~120 MB) are present on disk but gitignored — obtain from ORNL DAAC / AmeriFlux US-Skr for a fresh clone.

## Workflow

The full pipeline is orchestrated by `run_all.R`:

```bash
Rscript run_all.R       # run all steps
Rscript run_all.R 5     # run from step 5 onward
```

| Step | Script | Description |
|------|--------|-------------|
| 1-2 | `02_preprocess/*` | Chamber volumes/areas; goFlux auxfiles |
| 3 | `03_flux_calculation/*.R` | **Manual (RStudio):** goFlux processing with click.peak2 |
| 4 | `04_qc_rescue/build_missing_auxfiles.R` | Auxfiles for rescued measurements |
| 5-6 | `05_integration/*` | Assemble clean dataset; chamber corrections |
| 7-10 | `06_ebullition/*` | Detect, reprocess, integrate, and correct ebullition |
| 11-12 | `07_analysis/summary_table.R`, `manuscript_results.R` | Bootstrap stats; manuscript numbers |
| 13 | `09_tower_gpp/us_skr_gapfill_gpp.R` | Partition US-Skr tower GPP |
| 14-16 | `08_upscaling/*` | Methane + CO2 stand budgets; Monte Carlo forcing |
| 17 | `10_figures/publication_map_composite.R` | **Manual:** Fig 1 (map + photos) |
| 18-22 | `10_figures/` (fig2, fig3, plot_budget_figs, fig6_porewater_pca, plot_closure) | Main-text Figs 2-6 |
| 23-25 | `10_figures/figS1-figS3` | Supplementary Figs S1-S3 |

Steps 3 and 17 require interactive RStudio and are skipped by `run_all.R`. TLS-dependent steps (14-16) read the bundled `data/tls/`.

## Instruments

- 3x Los Gatos Research UGGA (model GLA131) -- CO2 and CH4 at 1 Hz
- 1x Picarro G4301 -- CO2 and CH4 at 0.17 Hz

## Dependencies

```r
# Core (here = portable project-root paths; data.table = tower GPP)
install.packages(c("here", "dplyr", "tidyr", "readr", "lubridate", "ggplot2",
                   "readxl", "openxlsx", "data.table"))

# Flux calculation
devtools::install_github("Qepanna/goFlux")

# Interactive QC app
install.packages(c("shiny", "plotly"))

# Figures and analysis
install.packages(c("patchwork", "ggh4x", "ggridges", "ggdist", "ggbeeswarm",
                    "ggrepel", "ggpubr", "cowplot", "scales", "forcats",
                    "lme4", "lmerTest", "emmeans"))

# Mapping
install.packages(c("sf", "rnaturalearth"))
```

Requires R >= 4.3.
